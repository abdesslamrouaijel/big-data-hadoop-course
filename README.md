# Big Data and Hadoop Complete Course (PDF)

An English-language, 86-page university-level Big Data and Hadoop study resource by Abdesslam Rouaijel. It combines core theory, Hadoop architecture, practical configuration, commands, diagrams, exercises, and exam preparation in one downloadable PDF.

[Download the complete Big Data and Hadoop course PDF](Big_Data_Hadoop_Complete_Course.pdf)

## What the course covers

- Big Data concepts, data characteristics, distributed systems, and the Hadoop ecosystem
- Hadoop architecture and HDFS: NameNode, DataNodes, blocks, replication, and common commands
- YARN resource management and MapReduce processing
- Configuration files, Hadoop services, ports, troubleshooting, and practical workflows
- Docker-based Hadoop examples and exam-focused review material

## Practical work and version notes

- **TP1:** Hadoop 3.3.6 installation and standalone/pseudo-distributed examples, with an optional BDE2020 Docker Hadoop 3.1.3 setup.
- **TP2:** Apache Hadoop 3.5.0 with Java 17 on an Ubuntu VM, focused on HDFS with one NameNode and two DataNodes initially (an optional third DataNode).

The two practicals have different Hadoop versions and deployment scopes; the course keeps those distinctions explicit.

## Exam preparation

Includes definitions, comparison questions, theoretical questions and answers, worked exercises, multiple-choice questions, troubleshooting guidance, revision sheets, and a mock examination with correction.
